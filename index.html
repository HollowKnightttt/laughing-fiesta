How to Join

Choose your platform below. Both Java Edition and Bedrock Edition use the same Server Address and Port!

Java Edition

  1. Launch Minecraft Java Edition.
  2. Click Multiplayer and then click Add Server.
  3. Set Server Name: i2b2t.
  4. Set Server Address: i2b2t.jo3.org:46265.
  5. Click Done and connect to the server!

Bedrock Edition

  1. Launch Minecraft Bedrock (Mobile/Win10/Console).
  2. Navigate to the Servers tab and click Add Server.
  3. Set Server Name: i2b2t.
  4. Set Server Address: i2b2t.jo3.org.
  5. Set Port: 46265 then click Play.
